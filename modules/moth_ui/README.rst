Mothlight
=========

Recording profiles for the Canon EOS M, with an animated panel over LiveView.

Press INFO in movie mode to open the panel, choose a profile with the
arrows or the wheel, press SET to apply it. Each profile shows whether
your card keeps up: continuous, on the edge, or burst only.

After every RAW clip, the module measures how well it compressed and uses
that for the next estimates.

Settings: Movie > Mothlight (theme, panel key, animations, card speed,
REC tally). Your own profiles: ML/SETTINGS/PROFILES.TXT.
